# SunD photoreal image prompts

Use these with an AI image generator (for example Gemini or ChatGPT image generation) to get photoreal lifestyle visuals in the style of the Sime Darby Property briefing deck.

## How to use

1. Paste one prompt at a time and ask for **16:9 landscape**, highest resolution available.
2. If a result has text, signs or logos, ask it to "remove all text and logos". The SunD labels and figures are added on top later, so they stay accurate.
3. Save each image here in `pitch/visuals/` with the file name shown. The deck will then use it in place of the illustration, with labels positioned over it.

Add this line to the end of every prompt:

> Photorealistic, natural daylight, warm tropical Malaysian setting, candid and lifestyle, high detail, shallow depth of field on the people, no text, no signage, no logos, no watermarks, 16:9.
